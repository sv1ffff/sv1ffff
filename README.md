### About Me
* **Full-Stack Software Engineer** and **Web Architect** based in Egypt.
* Specialized in designing high-throughput web applications, resilient backend architectures, and modern user interfaces.
* Focused on building end-to-end TypeScript solutions, cloud-native deployments, and distributed systems.
* **Core Competencies:**
  * **Scalable Web Systems:** Engineering low-latency web platforms with Next.js and NestJS.
  * **API & Systems Design:** Building resilient RESTful services, microservices, and asynchronous message queues.
